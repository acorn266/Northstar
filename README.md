# Northstar ✨

### Full-Stack Learning & Productivity Platform

**Northstar** is a full-stack web application designed to help learners turn their goals into structured learning paths, focused study sessions, measurable progress, and consistent habits.

It combines **learning management, productivity tracking, analytics, and AI-assisted learning** into one platform.

---

## 🚀 Live Demo

🌐 **[Open Northstar](https://northstar-alpha-six.vercel.app)**

---

## Features

- 📚 **Learning Paths** — Create and manage structured learning goals and track progress.
- ⏱️ **Focus Mode** — Run focused learning sessions with Pomodoro-style productivity tracking.
- 📊 **Analytics** — Visualize learning time, sessions, progress, and productivity.
- 🔥 **Streaks** — Track daily learning activity and build consistency.
- 🏆 **Achievements** — Unlock milestones based on learning progress and activity.
- 🤖 **Nova AI** — AI-assisted learning companion experience.
- 👤 **Authentication** — Registration, login, protected resources, and profile management.
- 📱 **Responsive UI** — Designed for desktop, tablet, and mobile.
